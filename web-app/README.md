# Курс перца горошек

Русскоязычный мобильный трекер 30-дневного курса. React, TypeScript, Tailwind CSS, Next.js App Router (Vinext), PWA.

## Запуск

Node.js 22.13+.

```sh
npm install
npm run dev
```

```sh
npm run build
npm start
```

В управляемой среде Sites установка выполняется `node scripts/install-ci.mjs`.

## Возможности

- Главная, Сегодня, Весь курс, Статистика, Настройки.
- Дни 1–15: от 1 до 15 горошин; дни 16–29: от 14 до 1; день 30: завершение, без горошин.
- Номер дня рассчитывается по локальной календарной дате, без влияния переходов на летнее время.
- Только текущий день доступен для отметки. Повторные отметки запрещены.
- Прогресс и настройки сохраняются в localStorage. Сброс с подтверждением.
- Установка PWA в Chrome на Android: меню → «Установить приложение».
- Service worker кэширует приложение для автономного открытия после первого посещения.
- Браузерные уведомления с разрешением пользователя, выбором времени и звука. Выполненный день исключается из напоминаний. «Напомнить позже» откладывает на час.

## Ограничения

Это устанавливаемое веб-приложение (PWA), не APK. Браузер не гарантирует локальные уведомления по расписанию при закрытом приложении. Таймер работает, пока приложение открыто; Android может приостанавливать фоновые вкладки. Для гарантированных напоминаний при закрытом приложении нужна нативная Android-оболочка и планировщик уведомлений.

Данные хранятся только в выбранном браузере. Очистка данных браузера удаляет отметки. При изменении даты начала отметки сохраняются по номеру дня. Статистика отражает фактически отмеченные дни; пропущенные дни не отмечаются автоматически.
